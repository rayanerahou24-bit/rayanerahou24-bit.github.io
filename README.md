# To-Do List Interactive 📝

## Description
Application web interactive pour gérer vos tâches quotidiennes. Interface moderne et intuitive avec filtres et statistiques en temps réel.

## 🚀 Technologies utilisées
- HTML5
- CSS3
- JavaScript (Vanilla)
- LocalStorage pour la persistance des données

## ✨ Fonctionnalités
- ✅ Ajouter des tâches
- ✅ Marquer comme terminées
- ✅ Supprimer des tâches
- ✅ Filtrer par statut (Toutes, Actives, Terminées)
- ✅ Statistiques en temps réel
- ✅ Sauvegarde automatique (LocalStorage)
- ✅ Interface responsive

## 📦 Installation et exécution

Aucune installation supplémentaire requise !
